# 월별 신규 카드 발급 이벤트 대시보드 (Card Promo Dashboard)

신규 카드 발급 및 이용유도 프로모션의 혜택과 조건(최소/최대)을 월별, 카드사별, 채널별로 비교 분석할 수 있는 웹 대시보드입니다.

## 주요 기능
- **단위 일원화**: 모든 금액(실적 조건, 캐시백)은 소수점 1자리 만원 단위(`15.0만원`, `12.5만원`)로 표기.
- **다차원 필터링**: 연월(`2026-09`), 채널(`카드고릴라`, `네이버페이`, `카카오페이` 등), 카드사 멀티 셀렉트.
- **Recharts 시각화**: 최소 조건 혜택과 최대 조건 혜택을 듀얼 컬러 막대 그래프로 비교.
- **관리자 크롤링 패널**: 금융 채널별 프로모션을 수집하여 로컬 `data/events.json`에 영구 병합 저장.

## 빠른 시작 (로컬 실행)

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 환경 변수 파일 생성
cp .env.example .env.local

# 3. 로컬 서버 시작
npm run dev
